# Image asset layout

- `activities/<year>/<event>/`: activity photos, grouped by year and event.
- `animations/`: animated media used by the site.
- `contact/`: contact QR codes and related assets.
- `icons/`: reusable UI icons.
- `logos/conferences/`: conference logos.
- `logos/education/`: university and educational organization logos.
- `logos/organizations/`: company and research organization logos.
- `logos/programs/`: internship and scholarship program logos.
- `media/`: media outlet and press assets.
- `paper_overview/`: the currently displayed overview image for each paper.
- `poster/`: academic posters.
- `profile/`: the current profile photo.
- `site/`: favicon, manifest, and other browser/site assets.
- `archive/`: unused historical variants retained for reference.

Use forward slashes in all Markdown, HTML, YAML, and Liquid paths. When moving
an asset, update every repository reference in the same commit.
